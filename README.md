## 🎯 算法题怎么写（重点）

**每道题一个文件，格式统一**。别写成 `Solution.java` 一坨，半年后你自己都看不懂哪道是哪道。

命名规范：

```
algorithm/01-数组/0001-两数之和-easy.java
algorithm/01-数组/0011-盛最多水的容器-medium.java
algorithm/07-二叉树/0094-二叉树的中序遍历-easy.java
```

每个文件的固定结构见 [`algorithm/00-模板.md`](algorithm/00-模板.md)，核心是**三段式**：

1. **题目**：题号 + 一句话描述 + 原题链接
2. **我的思路**：先写人话（你打算怎么解），再写代码
3. **复杂度 + 反思**：时间/空间复杂度；**这次卡在哪、下次怎么避免**

> ⚠️ **第 3 条最重要**。面试官不会问你"这题 AC 了吗"，
> 他会问"你为什么想到用哈希表"——答案就写在你的「我的思路」里。

**关于题解参考**：
- 参考了别人（LeetCode 题解 / 代码随想录 / labuladong）就在注释里**写明来源链接**
- 不要原样贴别人的代码当成自己的，**必须自己重写一遍再推上去**
- 这一条不只是道德问题——**你看懂 ≠ 你会写**，抄上去的代码面试时你讲不出来

## ⚠️ 关于把刷题代码传到 GitHub（重要）

**可以传，而且是好事。** 但要清楚三件事：

| 问题 | 答案 |
| --- | --- |
| 会不会被说"刷题不算项目"？ | 不会。**没有人会因为你会刷题扣分**，只会因为简历上没东西而扣分 |
| 招聘方会看吗？ | 大概率不会逐题看。他们看 **commit 频率**（连续性）和 **README**（总结能力） |
| 有风险吗？ | 有一个小风险：**公司面试题（非公开）不要传**。LeetCode 公开题随便传 |

> [!warning] 两个必须避开的坑
> 1. **别传面试真题**。有些公司在笔试/面试里用的题是保密的，传上去可能违反协议。
>    只传 LeetCode / 牛客 / 洛谷等**公开题库**的题。
> 2. **别原样抄题解**。自己重写 + 注明来源。这个行业圈子小，抄代码被发现的代价很大。

## 🔥 Commit 规范（简单版）

不用学 Conventional Commits，记住三种前缀就够：

```bash
git commit -m "feat: 数组-完成二分查找练习"
git commit -m "fix: 修复图书管理系统的空指针报错"
git commit -m "docs: 更新 README 进度看板"
```

**核心习惯：每天至少 push 一次，哪怕只写了一行。**

> 半年后招聘方看到的不是"你写了多少代码"，而是 **"这半年你有没有连续在写"**。
> 一个 200 天连续提交的绿格子墙，比 10000 行一次性上传的代码有说服力得多。

## 🚫 不要传到 GitHub 的东西

已经在 [`.gitignore`](.gitignore) 里配好了，这里说明为什么：

| 文件 | 为什么不要 |
| --- | --- |
| `*.class` | 编译产物，代码改了它就过期，会引起冲突 |
| `.idea/` `*.iml` | IDEA 的个人配置（含你的本地路径），别人用不了 |
| `out/` `target/` | 构建输出目录 |
| `*.log` | 日志文件，没用 |
| `.env` `application-local.yml` | **可能含密码、API Key**，传上去等于泄露 |

> [!danger] API Key 泄露是最严重的事故
> 后面学 LLM 时会用到 OpenAI / DeepSeek 的 Key。
> **永远不要写死在代码里**，用环境变量或 `.env` + `.gitignore`。
> 一旦推到 GitHub，机器人几秒钟就能扫到并盗刷，**记住这条能救你的钱包**。

```bash
# 1. 装 Git for Windows: https://git-scm.com/download/win  （一路默认下一步）

# 2. 身份（只做一次）
git config --global user.name "你的名字"

# 3. 在 GitHub 网页新建仓库 java-learning（不要勾选 Add README）

git remote add origin git@github.com:你的用户名/java-learning.git
git push -u origin main
```

之后每天：

```bash

```
