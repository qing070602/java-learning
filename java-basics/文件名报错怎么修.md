# 文件名报错怎么修

> 你在 IDEA 里看到 `class PracticeTemplate` 被标红 —— **这是我之前给的方案不严谨，现在修正。**

---

## 一、先说结论

**问题**：我让你「文件名用中文，类名保持 `PracticeTemplate`」，靠"不写 `public`"来绕开 Java 的命名限制。

**实测结果**：

| 检查方式 | 结果 |
| --- | --- |
| `javac` 命令行编译 | ✅ **不报错**（我三种情况都试过，全部 exit 0） |
| IDEA 的代码检查 | ❌ **标红**（IDEA 认为「类名和文件名不一致」是问题） |

**所以能编译，但 IDEA 会一直给你标红。** 满屏红线会让你分不清"真错误"和"假错误"，这对新手是灾难。**必须改掉。**

---

## 二、正确做法：文件名 = 类名（行业惯例）

Java 世界的规矩就一条：

> **文件名必须和类名完全一致。**

所以**文件名用英文**，类名跟着一样：

```
ArrayMax.java          →   public class ArrayMax { }
ArrayReverse.java      →   public class ArrayReverse { }
StudentScore.java      →   public class StudentScore { }
TwoSum.java            →   public class TwoSum { }
```

**中文写在哪？写在注释里。** 这才是真实项目的样子 —— 你去任何一家公司，代码文件都是英文名，注释和文档才是中文。

```java
/*
 * 题目：数组求最值          ← 中文在这里描述清楚
 * 知识点：数组遍历 / 求最值
 */
public class ArrayMax {        // ← 类名和文件名一致，IDEA 不标红
    public static void main(String[] args) { ... }
}
```

## 三、把你现在那个文件改过来（3 步）

**第 1 步：改文件名**

在 IDEA 左侧项目树里：
1. 右击 `练习-数组求最值.java`
2. `Refactor` → `Rename`（快捷键 `Shift + F6`）
3. 改成 **`ArrayMax.java`**
4. 弹出提示问要不要一起改类名 → **点 Rename**（IDEA 会自动把 `class PracticeTemplate` 改成 `class ArrayMax`）

**第 2 步：加上 public**

```java
public class ArrayMax {        // ← 补上 public
```

> 文件名和类名一致之后，就可以放心写 `public` 了。

**第 3 步：删掉那段"用法说明"注释**

`ArrayMax.java` 我已经放了一份现成的，你**直接用那个**，然后把 `练习-数组求最值.java` 删掉就行。

```powershell
cd D:\code\java-learning
del "java-basics\01-入门语法\练习-数组求最值.java"
git add -A
git commit -m "refactor: 练习文件改名，文件名与类名保持一致"
git push
```

## 五、如果你还想用中文文件名（不推荐，但可行）

唯一的办法是**不写 `public`**，并且**接受 IDEA 的黄色警告**（不是红色错误）：

```java
class PracticeTemplate {    // 不写 public，文件名可以是中文
```

**为什么不推荐：**

1. 你以后写项目（`Book.java`、`User.java`）必须用 `public`，**早点习惯英文命名**
2. 面试官看你的 GitHub，**英文文件名显得更专业**
3. 满屏黄色警告，会让你麻木，真错误也会被忽略

**结论：用英文文件名。中文写在注释和 README 里。**

## 六、这次踩坑的收获（记到你自己的笔记里）

> **"能编译"不等于"写法正确"。**
>
> `javac` 只在语言层面较真，IDEA 还会按行业规范检查。
> 一个好的写法要同时满足：**编译通过 + IDE 无警告 + 别人一眼看得懂。**
>
> 这也是面试会问的东西 —— 面试官看你的代码，第一眼看的就是**命名规范**。
