## 一、目录怎么分

按**课程章节**分，一个章节一个文件夹：

```
java-basics/
├── 01-入门语法/     变量、运算符、判断、循环、数组（黑马 1-4 章）
├── 02-方法/         方法、重载、递归（黑马 5-7 章）
├── 03-面向对象/      类、封装、继承、多态、接口、内部类（黑马 8-11 章）
├── 04-集合与泛型/    List / Set / Map / Stream / Lambda
├── 05-常用API/      String / StringBuilder / Date / 包装类（黑马 12、14 章）
├── 06-异常与IO/     异常体系、文件读写、序列化
├── 07-多线程与JUC/  线程、线程池、锁
├── 08-网络编程/      Socket / HTTP
└── 09-JVM探索/      内存结构、GC 实验代码
```

> 文件夹名 = 你 Obsidian 笔记的章节名，两边能对上，复习时不会迷路。

## 二、文件怎么命名 ⚠️ 最重要

> [!important] 铁律：**文件名 = 类名，都用英文**
> Java 规定文件名必须和 `public` 类名完全一致。所以文件名用**英文**，类名跟着一样：
>
> ```
> ArrayMax.java        →   public class ArrayMax { }
> ArrayReverse.java    →   public class ArrayReverse { }
> BubbleSort.java      →   public class BubbleSort { }
> ```
>
> **中文写在哪？写在文件头注释里**（见第三节）。这才是真实项目的样子 ——
> 你去看任何一家公司的代码，文件名都是英文，注释和文档才是中文。
>
> ❌ **不要用中文文件名**。踩过的坑记录在 [文件名报错怎么修.md](文件名报错怎么修.md)：
> 中文文件名（如 `练习-数组求最值.java`）会让 IDEA 无法把文件名和类名对齐，**一直标红**。
> 虽然 `javac` 能编译通过，但满屏红线会让你分不清真假错误。

**命名规则：英文驼峰，能看出练的是什么**

| 练习内容 | 文件名 / 类名 |
| --- | --- |
| 求最大值 | `ArrayMax` |
| 数组反转 | `ArrayReverse` |
| 查找元素 | `ArraySearch` |
| 冒泡排序 | `BubbleSort` |
| 二分查找 | `BinarySearch` |
| 学生成绩统计 | `StudentScore` |
| 字符串反转 | `StringReverse` |
| 判断素数 | `PrimeCheck` |
| 九九乘法表 | `MultiplicationTable` |
| 猜数字游戏 | `GuessNumber` |

**同一主题多个版本，加后缀**：

```
ArrayReverse.java              第一个版本
ArrayReverseByTwoPointer.java  双指针版
ArrayMaxWithMethod.java        抽成方法版
```

> 不会起名就问 AI：「Java 里『数组反转』这个练习，文件名叫什么好？」

### ❌ 三个必须避开的命名

| 错误写法 | 为什么不行 | 正确写法 |
| --- | --- | --- |
| `Demo1.java` `Test2.java` `A.java` | **两周后你自己都不知道里面是什么** | `ArrayMax.java` |
| `练习-数组求最值.java` `lianxi.java` | 中文/拼音，IDEA 标红、面试官看不懂 | `ArrayMax.java` |
| `Test1.java` `Test2.java` `Test3.java` | 只有编号没有内容，等于没有名字 | `BubbleSort.java` |

> [!tip] 自检方法
> 半年后面试官（或你自己）只看文件名，**能不能知道这道题在练什么？**
> 能 → 合格。不能 → 改名。

## 三、每个文件头部必须写清楚（6 行）

**不用写很长，就这 6 行。** 这是你半年后能回想起"我当时在干嘛"的唯一依据。

```java
/*
 * 章节：04 数组
 * 分P：p63-p68
 * 知识点：数组遍历 / 求最值 / 类型转换
 * 练习要求：键盘录入 5 个成绩，求最高分和平均分
 * 日期：2026-09-20
 * 状态：✅ 独立完成 / 🟡 参考了老师代码 / 🔴 只会抄
 */
```

**`状态` 那一行最重要** —— 填 🔴 的文件，就是你该回头重做的。

## 四、代码中间要有注释（但不是每行都写）

**写「为什么」，不写「做什么」：**

```java
// ❌ 废话注释
int max = arr[0];   // 把 arr[0] 赋值给 max

// ✅ 有价值注释
int max = arr[0];   // 从第一个元素开始比，比从 0 开始更安全（数组可能全是负数）

// ✅ 记录你踩过的坑
// 注意：这里必须先判断 i < arr.length，否则最后一个元素会比较两次
// 我当时写成了 i <= arr.length，报了 ArrayIndexOutOfBoundsException
```

> 判断标准：**这行注释能不能让未来的你少踩一次坑？** 不能就别写。

## 五、commit 信息怎么写

**格式：`类型: 章节 - 具体做了什么`**

```powershell
git commit -m "feat: 数组章节 - 完成求最值与反转练习"
git commit -m "feat: 方法章节 - 递归求阶乘"
git commit -m "fix: 修复求平均分时的整数除法问题"
git commit -m "docs: 更新 README 进度看板"
```

| 前缀 | 用在 |
| --- | --- |
| `feat:` | 加了新代码 |
| `fix:` | 修了 bug |
| `docs:` | 只改文档 |

## 七、什么时候该把练习升级成「项目」

练习是**单文件、几十行**；项目是**多文件、有结构、能演示**。

当一道练习满足下面任意两条，就该考虑搬去 `../projects/`：

1. 超过 3 个类，且类之间有继承/接口关系
2. 需要读写文件或数据库（有"数据持久化"）
3. 有完整的增删改查流程
4. 你能对着它讲 3 分钟不卡壳

**你的第一个项目**：黑马课程第 13 章学完后，把控制台**图书管理系统**做成 `projects/01-图书管理系统/`。
这是 S1 阶段的里程碑（2026 年 11 月），也是第一个能写进简历的东西。

```powershell

```

刷新 https://github.com/qing070602/java-learning —— **你会看到自己的绿格子。**

> [!tip] 用命令行验证能不能跑（可选）
> ```powershell
> cd D:\code\java-learning\java-basics\01-入门语法
> javac -encoding UTF-8 ArrayReverse.java
> java "-Dstdout.encoding=UTF-8" ArrayReverse
> ```
> - 文件名和类名一致时，`javac` 和 `java` 都直接用这个名字，不用绕弯
> - `"-Dstdout.encoding=UTF-8"` **必须带引号**，否则 PowerShell 会把等号两边拆开、报 `ClassNotFoundException`。加上它中文才不会乱码
> - 编译生成的 `.class` 文件已被 `.gitignore` 挡住，不会污染提交

## 九、中文乱码怎么办

如果你的 `System.out.println("开始练习")` 在控制台输出成 `��ʼ��ϰ��`：

**这不是你的代码错了**，是 JVM 输出编码和控制台对不上（Windows 控制台默认 GBK / cp936）。

**三个解法，按推荐顺序：**

| 方案 | 做法 | 适用 |
| --- | --- | --- |
| **① 用 IDEA 跑** | IDEA 的控制台默认就是 UTF-8，不会有这个问题 | ✅ 最省事，推荐 |
| **② 加 JVM 参数** | 命令行：`java "-Dstdout.encoding=UTF-8" ArrayMax`<br>IDEA：Run → Edit Configurations → VM options 填 `-Dstdout.encoding=UTF-8` | 需要命令行运行时 |
| **③ 改控制台** | 运行前先敲 `chcp 65001` | 时好时坏，不推荐 |

> [!note] 为什么会这样
> 你文件里存的是标准 UTF-8（我验证过：`开` = `E5 BC 80`，正确）。
> 编译也没问题。问题只出在**"JVM 把文字吐给控制台"这一步**——
> Java 25 在 Windows 上探测到的控制台编码和实际不符，就把中文替换成了 `?`。
> 记住一句话：**源文件存 UTF-8，编译加 `-encoding UTF-8`，运行加 `-Dstdout.encoding=UTF-8`，就一直不会乱码。**
