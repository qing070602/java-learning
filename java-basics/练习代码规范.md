> 这个文件夹放**上课练习题**（黑马 Java 课程配套练习）。

## 一、目录怎么分

按**课程章节**分，一个章节一个文件夹：

```
java-basics/
├── 01-入门语法/     变量、运算符、判断、循环、数组（黑马 1-4 章）
├── 02-方法/         方法、重载、递归（黑马 5-7 章）
├── 03-面向对象/      类、封装、继承、多态、接口、内部类（黑马 8-11 章）
├── 04-集合与泛型/    List / Set / Map / Stream / Lambda
├── 05-常用API/      String / StringBuilder / Date / 包装类（黑马 12、14 章）
├── 06-异常与IO/     异常体系、文件读写、序列化
├── 07-多线程与JUC/  线程、线程池、锁
├── 08-网络编程/      Socket / HTTP
└── 09-JVM探索/      内存结构、GC 实验代码
```

> 文件夹名 = 你 Obsidian 笔记的章节名，两边能对上，复习时不会迷路。

## 二、文件怎么命名 ⚠️ 最重要

**格式：`类型-具体内容.java`**

| 类型前缀 | 用在哪 | 例子 |
| --- | --- | --- |
| `练习-` | 课程里的练习题 | `练习-数组求最值.java` |
| `Demo-` | 跟着视频敲的演示代码 | `Demo-键盘录入求和.java` |
| `案例-` | 完整小案例 | `案例-学生成绩统计.java` |
| `实验-` | 自己瞎折腾验证某个知识点 | `实验-字符串常量池.java` |
| `工具-` | 可复用的工具类 | `工具-数组打印.java` |

> [!important] 文件名可以随便起，但类名要固定
> Java 规定 **`public` 类的名字必须和文件名完全一致**，而中文文件名做不到（`练习-数组求最值` 不是合法类名，因为有横线）。
> **解决办法：练习文件里不要写 `public`，类名统一用 `PracticeTemplate`。**
>
> ```java
> class PracticeTemplate {          // ← 不要写 public
>     public static void main(String[] args) { ... }
> }
> ```
>
> 复制 `01-入门语法/PracticeTemplate.java` 就自带这个结构，不用记。
> 等学到第 8 章面向对象、开始写真实项目时，才需要 `public` 类，那时候文件名就会规范成 `Book.java`、`User.java` 这种。

**同一主题多个文件加编号**：

```
练习-数组求最值.java
练习-数组求最值-方法版.java
练习-数组反转.java
练习-数组反转-双指针版.java
```

### ❌ 三个必须避开的命名

| 错误写法 | 为什么不行 | 正确写法 |
| --- | --- | --- |
| `Demo1.java` `Test2.java` `A.java` | **两周后你自己都不知道里面是什么** | `练习-数组求最值.java` |
| `demo.java` `lianxi.java` | 拼音/小写混用，搜索时找不到 | 统一中文描述 或 英文驼峰 |
| `练习1.java` `练习2.java` | 只有编号没有内容，等于没有名字 | `练习-求最大值.java` |

> [!tip] 自检方法
> 半年后面试官（或你自己）只看文件名，**能不能知道这道题在练什么？**
> 能 → 合格。不能 → 改名。

## 三、每个文件头部必须写清楚（6 行）

**不用写很长，就这 6 行。** 这是你半年后能回想起"我当时在干嘛"的唯一依据。

```java
/*
 * 章节：04 数组
 * 分P：p63-p68
 * 知识点：数组遍历 / 求最值 / 类型转换
 * 练习要求：键盘录入 5 个成绩，求最高分和平均分
 * 日期：2026-09-20
 * 状态：✅ 独立完成 / 🟡 参考了老师代码 / 🔴 只会抄
 */
```

**`状态` 那一行最重要** —— 填 🔴 的文件，就是你该回头重做的。

## 四、代码中间要有注释（但不是每行都写）

**写「为什么」，不写「做什么」：**

```java
// ❌ 废话注释
int max = arr[0];   // 把 arr[0] 赋值给 max

// ✅ 有价值注释
int max = arr[0];   // 从第一个元素开始比，比从 0 开始更安全（数组可能全是负数）

// ✅ 记录你踩过的坑
// 注意：这里必须先判断 i < arr.length，否则最后一个元素会比较两次
// 我当时写成了 i <= arr.length，报了 ArrayIndexOutOfBoundsException
```

> 判断标准：**这行注释能不能让未来的你少踩一次坑？** 不能就别写。

## 五、commit 信息怎么写

**格式：`类型: 章节 - 具体做了什么`**

```powershell
git commit -m "feat: 数组章节 - 完成求最值与反转练习"
git commit -m "feat: 方法章节 - 递归求阶乘"
git commit -m "fix: 修复求平均分时的整数除法问题"
git commit -m "docs: 更新 README 进度看板"
```

| 前缀 | 用在 |
| --- | --- |
| `feat:` | 加了新代码 |
| `fix:` | 修了 bug |
| `docs:` | 只改文档 |

## 七、什么时候该把练习升级成「项目」

练习是**单文件、几十行**；项目是**多文件、有结构、能演示**。

当一道练习满足下面任意两条，就该考虑搬去 `../projects/`：

1. 超过 3 个类，且类之间有继承/接口关系
2. 需要读写文件或数据库（有"数据持久化"）
3. 有完整的增删改查流程
4. 你能对着它讲 3 分钟不卡壳

**你的第一个项目**：黑马课程第 13 章学完后，把控制台**图书管理系统**做成 `projects/01-图书管理系统/`。
这是 S1 阶段的里程碑（2026 年 11 月），也是第一个能写进简历的东西。

> [!tip] 用命令行验证能不能跑（可选）
> ```powershell
> cd D:\code\java-learning\java-basics\01-入门语法
> javac -encoding UTF-8 "练习-数组求最值.java"

> - 编译生成的 `.class` 文件已被 `.gitignore` 挡住，不会污染提交

## 九、中文乱码怎么办

如果你的 `System.out.println("开始练习")` 在控制台输出成 `��ʼ��ϰ��`：

**这不是你的代码错了**，是 JVM 输出编码和控制台对不上（Windows 控制台默认 GBK / cp936）。

**三个解法，按推荐顺序：**

| 方案 | 做法 | 适用 |
| --- | --- | --- |
| **① 用 IDEA 跑** | IDEA 的控制台默认就是 UTF-8，不会有这个问题 | ✅ 最省事，推荐 |
| **② 加 JVM 参数** | 命令行：`java "-Dstdout.encoding=UTF-8" PracticeTemplate`<br>IDEA：Run → Edit Configurations → VM options 填 `-Dstdout.encoding=UTF-8` | 需要命令行运行时 |
| **③ 改控制台** | 运行前先敲 `chcp 65001` | 时好时坏，不推荐 |

> [!note] 为什么会这样
> 你文件里存的是标准 UTF-8（我验证过：`开` = `E5 BC 80`，正确）。
> 编译也没问题。问题只出在**"JVM 把文字吐给控制台"这一步**——
> Java 25 在 Windows 上探测到的控制台编码和实际不符，就把中文替换成了 `?`。
> 记住一句话：**源文件存 UTF-8，编译加 `-encoding UTF-8`，运行加 `-Dstdout.encoding=UTF-8`，就一直不会乱码。**
